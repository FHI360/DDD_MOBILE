# DDD Mobile User Manual 

 

## Introduction 

 

This document is designed to guide you through the various features and functionalities of the DDD mobile app, helping you make the most out of the mobile application. This manual will provide you with the necessary information to navigate and utilize the app effectively. Presently, the DDD application (August 2023) is used in Liberia and Cote’Divore 

 

## 1. Getting Started 

### 1.1. System Requirements 

Before using the DDD Mobile App, ensure that your mobile device meets the following minimum system requirements: 

 

- Operating System: Android 10 or higher  

- RAM: 3GB (recommended 4GB or higher) 

- Storage: 32GB (A minimum of 500MB free space) 

 

### 1.2. Installation 

 

To install the Mobile App on your mobile device, follow these steps: 

1. Use the latest version in the release repository in the release branch. 

All present and future releases can be found here. 

https://github.com/FHI360/app_releases/releases  

As at the time of writing this guide, the latest build can be found in the link using. 

https://github.com/FHI360/app_releases/releases/download/v2023.1.1.3/DDD.v2023.1.1.3.apk  

2. Download the latest version and install. 

3. Once the installation is complete, the flash screen appears with the DDD app icon before the log in page. This represents the theme of the application.

## 2. App Overview 

### 2.1. Logging In 

If you already have an account, you can log in by following these steps: 

1. Enter your authorized username and password. This is provided by the system administrator. On first login requires that you are connected to the internet. 

2. Provide the server address the DDD mobile app will be working with. Ensure that this is pointing to the server address given to you by the system administrator. 

3. Tap on the " Sign In" button to access your account.

### 2.2. Navigation Menu 

 

The navigation menu can usually be accessed by tapping on the menu icon (three horizontal lines) located in the top-left of DDD app. It provides a list of options or sections available in the app, allowing you to switch between different screens easily. Presently, there are 4 options in the navigation menu. 

- **Patients**: Create, search, devolve, administer, and discontinue patients’ administration. 

- **Report**: Generate missed appointment reports and refill report. 

- **Synchronization**: Sync configuration data and patients records with the server. 

- **Sign out**: Sign out Browse images, videos, or other media content.

## 4. Records administrations 

### 4.1. Synchronisation 

Synchronization should be done before any operation. This synchronization process helps avoid data loss, helps to aggregate data in the server, and ensure accurate reporting. Also, this ensure that data from the different outlets come together in a single location. Auditing is enabled to track the records being synced to the server for audit purposes. 

 

Navigate to Synchronization tab in the navigation menu. 

Click on the “Synchronize” button (figure 4)

## 5. Troubleshooting 

### 5.1. Common Issues 

In case you encounter issues while using the app, here are some common troubleshooting tips: 

- Check your internet connection. 

- Ensure your device meets the system requirements. 

- Update the app to the latest version. 

- Restart the app or your device. 

 

### 5.2. Reporting Bugs 

If you discover any bugs or problems with the app, please report them to the app's support team through the program officer. The ISS business solutions team will address the bugs. The DDD program team will provide detailed information about the issue and steps to reproduce it for faster resolution.
